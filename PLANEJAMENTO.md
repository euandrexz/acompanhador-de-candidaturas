# Acompanhador de candidaturas

## Problema que resolve
Ajuda a organizar vagas e acompanhar o andamento dos processos seletivos.

## Funcionalidades da primeira versão
- Cadastrar uma candidatura
- Listar candidaturas
- Editar uma candidatura
- Excluir uma candidatura
- Filtrar candidaturas por status

## Dados de cada candidatura
- Empresa
- Cargo
- Link da vaga (opcional)
- Data da candidatura
- Status
- Observações (opcional)

## Fora do escopo inicial
- Login
- Gráficos
- Notificações
